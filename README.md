# 教檢刷題王｜可直接刷題版

這不是只有網站骨架，已內含 115 年度題庫資料、官方答案、AI 詳解與題目圖片。

## 使用
直接用 VS Code Live Server、Python HTTP Server 或 GitHub Pages 開啟 `index.html`。

若本機測試：
`python -m http.server 8000`
然後開啟 `http://localhost:8000/`
